# Release provenance

This directory is a scoped reproducibility release for the AURORA-SR
synthetic mission-scheduling experiment. It was assembled from the project
working tree and committed before publication so the repository history
records when this release became available.

## Included

- The simulator and orbital/resource-model utilities used for the AURORA
  experiment.
- The experiment configuration, executed aggregate outputs, decision records,
  figures, and report generated by the recorded run.
- Compact validation summaries that support the limitations described in the
  report.

## Excluded

- The manuscript itself.
- The approximately 1.1 GB cached drought dataset.
- Model checkpoints, private databases, credentials, runtime caches, and
  Python bytecode.
- Broader application and training code not required to reproduce the
  synthetic scheduler experiment.

The excluded material is not represented as a claim of independent
reproducibility. Results must be interpreted under the simulator assumptions
and limitations documented in `results/research_report.md`.
