# Optional validation source

`test_end_to_end_more_regions.py` is archived here because it was used in the
broader project validation work. It is not part of the self-contained
synthetic AURORA scheduler experiment.

Running it requires the omitted drought-training modules and checkpoints,
network access to the Microsoft Planetary Computer, and the corresponding
remote-sensing dependencies. Its outputs must therefore not be interpreted as
reproducible from this release alone.
